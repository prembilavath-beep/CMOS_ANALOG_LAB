# CMOS Analog IC Laboratory

## Analog CMOS Circuit Design, Compensation, Filters & VCO

This repository contains my work from the **CMOS Analog IC Laboratory**,
covering the design, simulation, and analysis of several important
analog integrated-circuit building blocks using CMOS technology.

The laboratory work covered the complete analog IC design flow, starting
from operational-amplifier architectures and biasing circuits and
progressing toward frequency compensation, active-filter design, and
voltage-controlled oscillator (VCO) design.

### Topics Covered

- Two-stage CMOS operational amplifier
- Folded-cascode operational amplifier
- Bandgap Reference (BGR)
- Miller compensation
- Feed-forward compensation
- Sallen-Key active filters
- Butterworth filter
- Bessel filter
- Chebyshev filter
- Current-starved VCO

# 3. Two-Stage CMOS Operational Amplifier

The two-stage CMOS operational amplifier was designed and analyzed as
one of the fundamental amplifier architectures.

The two-stage architecture consists of:

- Differential input stage
- Active current-mirror load
- Second gain stage
- Bias circuit
- Frequency compensation network

The first stage provides differential amplification while the second
stage provides additional voltage gain and output-driving capability.

---

## 3.1 Design Parameters

The important design parameters considered include:

- DC gain
- Unity-gain bandwidth
- Phase margin
- Slew rate
- Input common-mode range
- Output swing
- Power consumption
- Load capacitance
- Compensation capacitance

---

## 3.2 DC Analysis

The DC operating point was analyzed to determine:

- Drain currents
- Gate-source voltages
- Drain-source voltages
- Overdrive voltages
- Transconductance
- Output conductance

The operating regions of all transistors were in Saturation.

---

## 3.3 Small-Signal Analysis

The two-stage op-amp was analyzed using AC simulation.

The following characteristics were obtained:

- Open-loop gain
- Gain-bandwidth product
- Unity-gain frequency
- Phase response
- Phase margin
- Gain margin

The approximate low-frequency gain can be expressed as:

    Av ≈ A1 × A2

where:

    A1 = gain of first stage
    A2 = gain of second stage

# 4. Folded-Cascode Operational Amplifier

A folded-cascode operational amplifier was also designed and analyzed.

The folded-cascode topology was studied as a high-gain, high-speed
single-stage amplifier architecture.

Important characteristics studied include:

- High voltage gain
- High output resistance
- Wide input common-mode range
- Frequency response
- Unity-gain bandwidth
- Stability
- Output swing
- Power consumption

---

## 4.1 Design Considerations

The folded-cascode design requires careful selection of:

- Bias currents
- Transistor dimensions
- Overdrive voltages
- Cascode transistor dimensions
- Current-mirror ratios

The transistor operating regions were verified using DC operating-point
analysis and all are in Saturation.

---

## 4.2 Small-Signal Gain

The gain is approximately determined by:

    Av ≈ gm × Rout

where:

    gm   = effective transconductance
    Rout = output resistance

The cascode structure increases the effective output resistance and
therefore increases the voltage gain.

# 8. Miller Compensation

Miller compensation was implemented for the multi-stage op-amp.

A compensation capacitor is used to modify the pole locations of the
amplifier.

The basic concept is:

    Compensation capacitor
            ↓
    Pole splitting
            ↓
    Dominant pole
            ↓
    Improved stability

Miller compensation was analyzed using AC simulation.

The following parameters were studied:

- Unity-gain bandwidth
- Phase margin
- Gain margin
- Dominant pole
- Non-dominant pole
- Stability

---

## 8.1 Miller Compensation Analysis

The effect of changing compensation capacitance was investigated.

Important observations include:

- Increasing compensation generally lowers the dominant pole.
- Unity-gain bandwidth is affected by the compensation capacitor.
- Phase margin depends on pole locations.
- Excessive compensation can reduce bandwidth.

The exact behavior and final values are obtained from Cadence simulation.
